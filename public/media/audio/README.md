# Rights-cleared audio assets

Place only audio files that STARMUSICS has explicit permission to distribute here. Do not commit commercial recordings merely because they can be downloaded or streamed elsewhere.

Use stable filenames such as `track-slug.mp3` and register each file in `data/audio-library.json`. Keep original contracts and sensitive documents outside the public repository; use an internal evidence reference in the manifest. A manifest entry is not legal advice or an automatic authorization to publish.

Supported manifest MIME types: `audio/mpeg`, `audio/mp4`, `audio/aac`, `audio/ogg`, `audio/opus`, `audio/wav`, `audio/flac`, `audio/webm`.
